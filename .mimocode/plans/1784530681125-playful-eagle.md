# Plan: Fix Select dropdowns to display Persian values

## Problem
The `@base-ui/react` Select component displays the `value` prop (English text like "PENDING", "FULL_DAY", "SATURDAY") instead of the `children` (Persian text like "در انتظار", "تمام روز", "شنبه") in the trigger/selected state.

## Root Cause
`@base-ui/react`'s `Select.Value` displays the internal `value` by default, not the text content of the selected `SelectItem`. The fix is to use the `getValueLabel` prop on the `Select` root to map values to their display labels.

## Files to Modify

### 1. `components/ui/select.tsx`
- Add `getValueLabel` prop support to the `Select` component wrapper
- Pass it through to `SelectPrimitive.Root`

## Implementation Approach

Option A: Add `getValueLabel` to each `Select` instance individually
- Simple, no component changes needed
- Repetitive but clear

Option B: Create a `labelMap` object and pass it to `Select`
- Cleaner, less repetition
- Requires understanding `@base-ui/react` Select API

**Recommended: Option A** — Direct `getValueLabel` function on each Select, since each has a small unique mapping.
