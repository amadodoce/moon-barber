# Plan: Hallmark Audit of Barber Shop UI

## Scope

Audit the **entire existing design** of the barber-shop project against Hallmark's anti-pattern catalog. This is a read-only audit — no code changes, no redesign. The output is a ranked punch list of findings grouped by severity.

## What Gets Audited

## Audit Methodology

For each file, check against Hallmark's 58 slop-test gates and the anti-pattern catalog. Key checks:

### Structural
- Is it the generic AI template (hero → 3 features → CTA → footer)?
- Is the nav the AI default (wordmark-left, links-centred, CTA-right)?
- Is the footer the AI default (4 columns + social + copyright)?
- Is the hero centred-everything with min-height: 100vh?

### Visual
- Purple gradients? Gradient text?
- 3-equal-column card grids with icon-above-heading?
- Card-in-card nesting?
- Side-stripe cards?
- Pure #000 or #fff?
- Inter/Roboto everywhere?

### Microinteractions
- transition-all?
- Universal hover:scale-105?
- Bouncy easings?
- Multiple hover effects per element?
- Animating width/height/top/left?
- Focus rings that fade in?
- Celebratory toasts?

### Typography
- More than 3 font families?
- Italic headers?
- Display type paired well?

### Token Discipline
- Inline hex/OKLCH values outside tokens?
- Mid-render improvisation?

### Contrast
- Text on dark backgrounds readable?
- Gold on dark sufficient contrast?

### Responsive
- Horizontal scroll on any viewport?
- Two-line clickable text?
- Image grids without minmax?

### Honest Copy
- Invented metrics?
- Placeholder names?

### Layout-Safety
- Sticky element bleed?
- Section eyebrow beside heading?

## Output Format

```
[severity] Tell name — file:line
  why it's a tell (one line)
  → fix (one line)

Summary — N critical · M major · K minor
Verdict — [ships as slop | reads as AI-generated | close, fix the minors]
```

## Execution Steps

1. Read all landing page components in parallel
2. Read globals.css and layout files
3. Read booking flow components
4. Read admin components
5. Compile findings against anti-pattern list
6. Group by severity, write final audit report

## Key Anti-Patterns to Watch For (from the existing design)

Based on the explore agent's findings, likely high-signal checks:
- **3-column feature grid** (Services.tsx, Barbers.tsx, HowItWorks.tsx all use 3-col grids)
- **Centred everything** (Hero, HowItWorks, FinalCTA are all centred)
- **Full-viewport centred hero** (Hero.tsx uses min-h-[85vh] with centred content)
- **Pure black** (#0A0A0A is close to #000)
- **Geometric decorative shapes** in Hero/About — could read as floating-orb decoration
- **Hardcoded hex values** throughout Tailwind classes (not using CSS tokens)
- **AI nav pattern** (wordmark-left, links, CTA-button-right)
- **AI footer pattern** (3-column links + contact)
- **No Hallmark stamp** on any file
- **Card-in-card** potential in BookingSummary
- **Animate-on-scroll** potential (fade-in-up used in booking layout)
