# Landing Page Design Plan — Barber Shop

## Identity

**Editorial Web Designer** with a **Product UI overlay** — the page reads like a premium barbershop's editorial presence, but the booking CTA works like a product's primary action.

## Design Direction

A masculine, refined barbershop aesthetic: dark tones with warm amber/gold accents, strong typography, real photography feel (even if placeholder), and RTL Persian text throughout. The design should feel like walking into a well-designed barbershop — not a SaaS landing page.

---

## DESIGN.md

### 1. Objective

The landing page should make visitors feel: "This is a premium, trustworthy barbershop where I can book instantly." The quality bar is: every section earns its space, no filler, no generic AI patterns. Persian text throughout, RTL layout.

### 2. Product Context

- **What the product does:** Online appointment booking for a men's barbershop
- **Who it's for:** Iranian men (25-50) who want to book barbershop appointments quickly
- **Adjacent brands (feel like these):** Blind Barber (NYC), By Vilain, American Crew
- **Distant brand (do NOT feel like this):** Generic SaaS landing pages with gradient heroes
- **Cultural register:** Aspirational-masculine — premium but approachable

### 3. Visual Foundations

#### 3a. Color

- **Neutral scale:** Dark foundation — `#0A0A0A` (near-black), `#1A1A1A`, `#2A2A2A`, `#3A3A3A`, `#6A6A6A`, `#9A9A9A`, `#E5E5E5`, `#F5F5F5`
- **Accent(s):** `--accent-primary: #D4A853` (warm gold/amber), secondary: `#1A1A1A` (dark)
- **Usage rules:** Gold accent used sparingly — CTA buttons, key numbers, decorative lines. Never as background fills.

#### 3b. Typography

- **Display face:** Yekan (already loaded), weights: 700-900 for headings
- **Body face:** Yekan, weights: 400-500 for body text
- **Type scale:** 14 / 16 / 18 / 20 / 24 / 32 / 40 / 56 (px)

#### 3c. Spacing & rhythm

- **Base unit:** 8px
- **Section padding:** 80-120px vertical on desktop
- **Content max-width:** 1200px

#### 3d. Component seeds

- **Buttons:** Primary (gold bg, dark text), Ghost (border only, gold text)
- **Cards:** Dark bg with subtle border, no rounded-16px slop — use 8-12px radius
- **Icons:** Lucide React (already installed), stroke style

### 4. Accessibility

- Body text contrast: 4.5:1 minimum against dark backgrounds
- Focus indicators: gold outline on interactive elements
- All images: descriptive alt text in Persian

### 5. Voice & Tone

- **Register:** Professional, warm, confident
- **Words this brand uses:** حرفه‌ای (professional), تجربه (experience), اعتماد (trust)
- **Words this brand refuses:** "seamlessly", "unlock", "elevate", generic corporate language
- **Address:** "شما" (formal you)

### 6. Implementation Practices

- **Token format:** CSS variables in globals.css + Tailwind v4 @theme inline
- **Component library:** shadcn (already installed)
- **Image treatment:** Placeholder images with warm, moody barbershop photography aesthetic
- **Grid system:** Tailwind's default, max-width container

### 7. Anti-Patterns

- **No gradient hero.** Use a strong typographic hero with dark background instead.
- **No rounded-16px card grid.** Use asymmetric layouts and bordered containers.
- **No emoji decoration.** Use typography hierarchy and gold accent lines.
- **No generic "trust logos" strip.** Integrate social proof into real copy.
- **No testimonial carousel.** Show 2-3 static testimonials with real names.

## Structure — Landing Page Sections

### Section 1: Hero
- **Role:** First impression, immediate value proposition
- **Layout:** Full-width dark background, large centered Persian headline, subtext, single gold CTA button
- **Headline:** "آرایشگاه مردانه [Shop Name]"
- **Subtext:** "رزرو آنلاین نوبت در چند ثانیه"
- **CTA:** "رزرو نوبت" (links to /book)
- **Visual:** Decorative gold line or geometric pattern as background element

### Section 2: Services Preview
- **Role:** Show what the shop offers
- **Layout:** 3-column grid on desktop, stacked on mobile
- **Content:** 3 key services with icon, name, price, duration
- **Visual:** Dark cards with gold icon accents

### Section 3: How It Works
- **Role:** Reduce booking friction
- **Layout:** Horizontal 3-step flow with numbered circles
- **Steps:** 1. سرویس خود را انتخاب کنید → 2. زمان مناسب را رزرو کنید → 3. پرداخت آنلاین انجام دهید
- **Visual:** Gold numbered circles connected by a subtle line

### Section 4: About / Why Us
- **Role:** Build trust and differentiate
- **Layout:** Two-column — text left, decorative element right
- **Content:** Brief paragraph about experience, quality, professionalism
- **Visual:** Geometric pattern or barbershop-themed decorative element

### Section 5: Barbers / Team
- **Role:** Humanize the brand
- **Layout:** Horizontal cards for each barber
- **Content:** Name, specialty, years of experience
- **Visual:** Placeholder avatar circles with gold border

### Section 6: Testimonials
- **Role:** Social proof
- **Layout:** 2 testimonial cards side by side
- **Content:** Customer quote, name, service booked
- **Visual:** Dark cards with subtle gold border accent

### Section 7: Final CTA
- **Role:** Conversion
- **Layout:** Full-width dark section with centered content
- **Content:** Strong headline + gold CTA button
- **Headline:** "همین الان نوبت خود را رزرو کنید"

### Section 8: Footer
- **Role:** Contact info, hours, links
- **Layout:** 3-column — contact, hours, quick links
- **Content:** Phone, address, working hours, social links

## Decision Trace

1. **Dark theme for landing page** — Barbershops have a masculine, premium association. Dark backgrounds with gold accents convey this better than light/white themes. Alternative: keep the current light theme. Tradeoff: dark theme requires more careful contrast management.

2. **Gold/amber accent (#D4A853)** — Extends the existing amber-500 color already in use, but shifted slightly warmer/more golden for a premium feel. Alternative: pure amber (#F59E0B) or copper. Tradeoff: gold may feel less modern than pure amber.

3. **Section-by-section components** — Each section is its own component for maintainability. Alternative: single large page file. Tradeoff: more files to manage, but each is focused and editable.

4. **No photography in initial implementation** — Using decorative geometric elements and typography instead of photos, since we don't have actual barbershop photos. Alternative: placeholder images. Tradeoff: less visual impact than real photography, but avoids stock photo slop.

5. **RTL-first design** — All layouts are designed RTL-first, not LTR mirrored. Content flows right-to-left, asymmetric layouts anchor to the right.
